# CeTZ gallery

The example diagrams from CeTZ's own gallery, copied unmodified from
[cetz-package/cetz](https://github.com/cetz-package/cetz/tree/2477845c63ca8fa585919aa9ddfcd13b296b6e18/gallery)
at commit `2477845`. They are licensed under the LGPL-3.0 (see `LICENSE`),
not the editor's MIT license.

The compile tests in `crates/compile` run every file here, with and without
the editor's probe, so the editor keeps handling CeTZ's showcase diagrams.

To update, copy the `.typ` files from a newer CeTZ commit and change the
commit above.
